# Killer Detective Game

A nostalgic, pass-and-play party game for **3–20 players**.

## Run locally
1. Install Node.js LTS from https://nodejs.org/
2. Open this folder in VS Code.
3. Open Terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown in the terminal.

## Deploy to GitHub Pages
1. Use your existing GitHub repository (the one you created earlier, likely `wink-killer`).
2. Upload the files in this folder to the repository root.
3. In `vite.config.js`, the base path is `/wink-killer/`. If your repository has a different name, update the base path to `/<your-repository-name>/`.
4. In GitHub, open **Settings → Pages** and select **GitHub Actions** as the build source.
5. Wait for the deployment workflow to finish. Your site will be at `https://YOUR-USERNAME.github.io/wink-killer/`.

## Roles
- **4–20 players:** one Detective, one Police Officer, and the rest Civilians. One Civilian is secretly the Blinker.
- **3 players:** one Detective and two Civilians; one of those Civilians is the Blinker. The Police Officer role is skipped so there is someone for the Blinker to wink at.

The role dealing is private: pass the phone around and have each player reveal their role one at a time.
